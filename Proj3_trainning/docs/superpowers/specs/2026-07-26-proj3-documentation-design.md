# Proj3_trainning 文档与注释设计

## 目标

让第一次接触 ESDA 的读者能够从 `Proj3_trainning` 根目录开始，理解训练如何启动、数据如何流动、结果如何保存，以及目录中各类文件的职责。

## 范围

- 新增 `FILE_GUIDE.md`，逐目录说明项目内全部文件或同类文件组的用途。
- 扩充根目录 `README.md`，加入推荐阅读顺序、执行流程和文档入口。
- 为本项目编写的 `run.sh`、`setup_env.sh` 增加教学型注释。
- 只在 `software/main.py` 的本项目适配点附近增加注释。
- 不修改 ESDA、MinkowskiEngine、模型实现、配置值、权重或训练行为。

## 注释原则

- 注释解释“为什么这样做”和数据去向，不逐字复述语句。
- Shell 脚本按参数、校验、运行、持久化、关机分段。
- 上游代码通过文档介绍，不进行大面积逐行注释，便于以后与原仓库对照。
- 所有文本采用 UTF-8，兼容 AutoDL Linux 环境。

## 验证

- 使用 Bash 静态语法检查验证两个 Shell 脚本。
- 使用 Python AST/编译检查验证 `software/main.py`。
- 搜索新增文档中的路径，确认根目录入口和关键适配点均被覆盖。
